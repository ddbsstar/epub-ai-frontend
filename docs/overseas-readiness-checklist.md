# EPUB 海外试用任务单

建立日期：2026-10-29；执行更新：2026-10-31。状态：执行中。首轮英文模板适配与英文流程已提交 PR，尚未合并或部署；Kindle 实机验收由用户选择稍后进行。公开推广、域名购买和对外消息仍未执行。

当前范围是 EPUB 排版产品，与独立的“X 起号与热点 App 出海”项目分开管理。优先准备英语市场试用，具体国家、首要用户群和阅读器由 OS-01 确认。

## 建立任务时的基线（2026-10-29）

- 已有公开 HTTPS 试用、上传 → 规则排版 → 校验 → 私有下载的真实链路。
- 公开版关闭付费模型和插画；单书 20 MiB、匿名会话隔离、上传后 24 小时到期，具体配置见后端 `docs/public-beta.md`。
- 前端使用链路、页面 metadata 和错误提示主要为中文；没有可用的公开真实效果对比入口。
- 主要真实图书验证是中文书。两段合成英文片段只能证明普通语义标签可以排版、未知出版 class 会触发保护，不能代替真实英文书覆盖或阅读器验收。
- 首页 Kindle 为设计示意；EPUBCheck/正文完整性通过，不代表实机视觉效果已获用户认可。
- 站点目前全局返回 `X-Robots-Tag: noindex, nofollow`，符合邀请试用阶段的配置；搜索获客需要按公开与私有路由调整。

### 已跑通的真实处理结果

实际通过前端代理 → 独立 API/Worker → 私有 EPUB/报告下载，Alice EPUB 2 导出为 139,980 字节、SHA256 `b51c52924d21ac61d8b8b2c3941164894cd5d7a84066b813aef8ead5fc1e53ac`；9/14 个正文文档、635/778 段获得样式，其余保留。源与输出 EPUBCheck 5.4.0 均为 0 错误/0 警告。新分隔段计数与旧 `hr` 计数严格区分，修复了仅在完整业务链路暴露的发布失败；旧失败记录保留。

另一个真实模板返回 `UNSUPPORTED_RESOURCE`，未发布下载产物。相同的既有非致命格式问题允许保留，新增错误、数量增加和 fatal 才拒绝；不把所有源格式警告都说成必然失败。机器检查与真实视觉价值继续分别记录。

本轮 58 项真实 HTTP 断言验证上传、幂等开始、实际处理、下载、跨会话拒绝、失败与只读恢复。它们不是 58 次用户试用，也不代替完整浏览器点击或 Kindle 验收。后端 PR 包含 Linux 路径测试修复，前端 PR 包含精确统计的兼容更新；均无 main 直推、自动合并或生产部署。
