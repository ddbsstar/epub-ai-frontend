# 页面字体

Noto Sans SC 与 Noto Serif SC，采用 SIL Open Font License 1.1；授权原文见同目录 OFL 文件。
这两个 WOFF2 是首页、上传页及现有组件固定文案的字符子集，包含 ASCII 和当前业务页面、状态/错误提示等固定中文文案，并非完整中文字库。
更新文案时需补齐子集；未包含的字符会使用系统字体回退。字体通过 Vite 本地打包，无第三方字体请求。

上游：[Noto Sans SC](https://github.com/notofonts/noto-cjk/tree/main/Sans)、[Noto Serif SC](https://github.com/notofonts/noto-cjk/tree/main/Serif)。
